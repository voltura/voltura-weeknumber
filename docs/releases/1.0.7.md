# Voltura WeekNumber 1.0.7

- Week and date views now stay up to date after midnight.
- Improved support for regional calendars, including calendars with up to 56 weeks in a year.
- Fixed crashes when a date is outside the selected calendar's range or a color code is incomplete.
- Clearing a date now also clears its previous week-year information.
- Prevented overlapping update checks and installations.
